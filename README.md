# leetcode

Python notes for a few LeetCode problems. Some problems include more than one approach. The `recurs` folder holds short recursion examples: counting down, doubling until the value passes 100, reversing a string, and factorial.

The problems are Valid Parentheses, Longest Substring Without Repeating Characters, Median of Two Sorted Arrays, Permutations, Permutations II, Rotate Image, and Group Anagrams.

These notes were written from 22 May 2021 through 6 June 2021.
